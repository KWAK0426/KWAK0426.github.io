# 승인된 표시용 모자이크

2026-10-22 사용자가 제작 완료된 10/7 1회차 다분광 반사도 및 NDVI의 뷰어 배포를 요청했다. 이후 별도 확인에서 영상의 위치·촬영 범위 좌표와 표시용 Drive 파일 ID의 공개에 "이 범위 공개 승인"으로 명시적으로 동의했다. 원본 Photos·개별 GPS 목록·DEM·정량 TIFF·로컬 경로는 공개하지 않는다. Photos를 제외한 자료의 Drive 업로드 허용과 인터넷 전체 공개는 구분한다.

- `published_views.json`: 별도로 제작·검증한 표시용 COG의 승인된 등록 목록. 매일 자동 갱신할 때도 이 목록과 썸네일을 유지한다.
- 동일 id가 자동 조사 결과에도 있으면 이 명시적 등록을 우선한다. 다른 회차는 자동 조사 결과를 유지한다.
- 다분광 RGB는 B6/B4/B2이며 NDVI는 `(B10-B6)/(B10+B6)`이다. 현재 뷰어 표시는 viridis 0~1이며 원 분석값을 변경하지 않는다.
- Drive의 표시 파일은 3밴드 Byte JPEG COG다. 정량 분석의 입력이 아니며, 분석용 10밴드/NDVI TIFF는 별도로 보존한다.
- COG를 읽지 못하면 썸네일 미리보기로 전환하고 화면에 이를 명시한다. 썸네일을 원해상도 영상이라고 표시하지 않는다.
- NDVI에는 고정 컬러바를 표시한다. 비공개 DEM·GPS에 대해서는 '자료 없음'이나 공개 GSD 계산 가능 상태로 오표시하지 않는다.

공유 범위를 바꿀 때는 사용자 승인이 필요하다. 승인되지 않은 날짜나 원자료를 이 등록에 임의로 추가하지 않는다. Drive 상위 자료 폴더 전체를 공개하지 말고, 승인된 표시 파일만 공유한다.

## 2026-10-24 추가 공개 승인

사용자가 이번 배포에서 "검증된 새 자료도 공개 승인"으로 필지 경계·평균 스펙트럼·대표 화소값 및 다른 날짜의 검증된 1m RGB 영상 공개에 동의했다. 10/7 1차의 선택영상 경계와 정제된 회차 CSV도 같은 표시 자료 범위로 포함한다. 원본 Photos·개별 GPS·로컬 경로·분석 TIFF는 계속 제외한다. 19회차의 1m RGB는 실제 광학 카메라 영상이 아니라 기존 다분광의 축소 대체 영상이다.

뷰어는 표시와 저장된 회차 메타데이터 조회만 담당한다. GSD 일괄 계산 UI는 제거했으며 공유 데스크톱 자동화는 유지한다. 검증 범위와 보류 항목은 `drone/updates/20261024_verified_release.html`에 기록한다.

## 2026-10-22 밴드별 보기

사용자 요청에 따라 같은 회차에 파장순 10밴드(444, 475, 531, 560, 650, 668, 705, 717, 740, 842 nm) 보기와 Min–Max / P05–P95 컬러바를 추가했다. 기본은 P05–P95다. RGB 합성과 NDVI는 그대로 유지한다.

20개 표시 이미지(각 1000 × 715 px)와 반사도 범위·파장 정보를 기존 공개 GitHub 뷰어에 추가해도 되는지 별도로 확인했고, 2026-10-22 사용자가 "오케이 배포해보자"로 승인했다.

- `spectral` 메타데이터와 `bands/`의 무손실 WebP 20개는 표시용이다. 원본 10밴드 TIFF를 공개한 것이 아니다. 각 표시 영상은 1000 × 715 px다.
- 범위는 원래 격자의 alpha 유효 화소 92,778,737개 전체에서 밴드별 UInt16 히스토그램으로 정확히 계산했다. P05/P95는 선형 분위수이며 표시 축소본이나 현재 지도 화면에서 계산하지 않는다.
- 컬러맵은 viridis다. P05 아래와 P95 위는 각각 끝 색에 포화시키며, 원본 값이나 유효 영역을 변경하지 않는다. 유효 0/65535를 값만으로 제외하지 않는다.
- 반사도 숫자는 저장 UInt16 / 32768이다. 이 배율은 보정된 Metashape 규약과 프로젝트 기록에 따른 해석이며, 별도 내보내기 로그로 독립 확정한 값은 아니다. 표시 값이 1보다 크다는 이유로 원본을 1로 제한하지 않는다.
- 같은 회차의 표시용 지도 범위와 위치에 대한 기존 공개 승인을 유지한다. 개별 Photos·GPS 목록·DEM·분석 TIFF·로컬 경로는 추가하지 않는다.

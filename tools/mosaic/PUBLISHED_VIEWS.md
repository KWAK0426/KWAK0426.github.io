# 승인된 표시용 모자이크

2026-10-22 사용자가 제작 완료된 10/7 1회차 다분광 반사도 및 NDVI의 뷰어 배포를 요청했다. 이후 별도 확인에서 영상의 위치·촬영 범위 좌표와 표시용 Drive 파일 ID의 공개에 "이 범위 공개 승인"으로 명시적으로 동의했다. 원본 Photos·개별 GPS 목록·DEM·정량 TIFF·로컬 경로는 공개하지 않는다. Photos를 제외한 자료의 Drive 업로드 허용과 인터넷 전체 공개는 구분한다.

- `published_views.json`: 별도로 제작·검증한 표시용 COG의 승인된 등록 목록. 매일 자동 갱신할 때도 이 목록과 썸네일을 유지한다.
- 동일 id가 자동 조사 결과에도 있으면 이 명시적 등록을 우선한다. 다른 회차는 자동 조사 결과를 유지한다.
- 다분광 RGB는 B6/B4/B2이며 NDVI는 `(B10-B6)/(B10+B6)`을 먼저 계산한 뒤 -1~1 고정 색으로 표시한다.
- Drive의 표시 파일은 3밴드 Byte JPEG COG다. 정량 분석의 입력이 아니며, 분석용 10밴드/NDVI TIFF는 별도로 보존한다.
- COG를 읽지 못하면 썸네일 미리보기로 전환하고 화면에 이를 명시한다. 썸네일을 원해상도 영상이라고 표시하지 않는다.
- NDVI에는 고정 컬러바를 표시한다. 비공개 DEM·GPS에 대해서는 '자료 없음'이나 공개 GSD 계산 가능 상태로 오표시하지 않는다.

공유 범위를 바꿀 때는 사용자 승인이 필요하다. 승인되지 않은 날짜나 원자료를 이 등록에 임의로 추가하지 않는다. Drive 상위 자료 폴더 전체를 공개하지 말고, 승인된 표시 파일만 공유한다.

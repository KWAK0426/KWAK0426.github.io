# 승인된 표시용 모자이크

## 2026-10-25 공통 필지와 반사도 색상 범위

사용자 요청으로 같은 19개 필지 경계를 날짜·회차·영상 종류와 무관하게 공통 표시한다. 고유 번호 1~19와 기존 좌표는 그대로이며, `fields/gimhae-parcels-1-19.geojson`에는 경계와 번호만 있다. 날짜별 평균 반사도를 다른 날짜에 복사하지 않는다. 10/7의 회차별 통계는 경계·번호가 일치할 때만 해당 회차 경계에 결합한다.

- 다분광 밴드의 기본 컬러바는 각 날짜·회차·밴드의 **필지 안 유효 표시 화소 P05–P95**다. 원본 전체가 아니라 긴 변 1000px인 기존 대표 표시 격자에서, 공통 필지 합집합과 원본 alpha 유효 영역이 겹치는 화소를 사용한다. 필지 평균의 분위수가 아니며 중첩 필지를 이중 집계하지 않는다.
- 5/95 백분위는 도로·건물·타프 등 필지 밖 밝은 값의 영향을 배제하고 필지 내부 차이가 보이도록 하는 표시 기준이다. 물리적 정확도·품질 합격 기준이 아니다. 필지 안 극단값은 끝 색으로 포화할 뿐 원본 값·유효 영역을 삭제하지 않는다.
- 전체 Min–Max 선택은 기존 원본 전체 유효 영역의 정확한 범위를 유지한다. 날짜별 범위는 같지 않으므로 같은 색을 같은 반사도라고 해석하지 않고 컬러바 숫자로 확인한다.
- 분광반사도 밴드는 두 범위 모두 `RdYlBu_r`(낮음: 파랑, 높음: 빨강)다. RGB 합성은 RGB를 유지한다. NDVI 등 식생지수에는 viridis를 사용하며 기존 NDVI 0~1 표시 파일과 수치는 변경하지 않는다.
- 대표 격자의 각 셀 중심을 원본 CRS로 변환하고 원본 최근접 화소를 읽는다. LZW TIFF의 띠를 한 번씩 읽는 방식이며 값을 평균내거나 보정하지 않는다. 합성자료에서 GDAL 최근접 변환과 대조한다.
- 공통 경계는 스펙트럼 자료 유무와 독립적으로 표시하며 자동 갱신 후에도 유지한다. 원본 Photos·TIFF·개별 GPS·로컬 경로·비공개 Drive ID는 계속 제외한다.

## 2026-10-25 다분광 13회차 추가 연결

사용자가 Drive 업로드 후 "뷰어에서도 바로 볼 수 있게 업데이트 해줘"로 공개 뷰어 연결을 요청했다. 기존 10/7 1회차를 보존하고 5/10 3~5회차, 7/16 1회차, 7/31 1~2회차, 9/8 1~4회차, 9/23 1~3회차를 추가한다. 다분광 14회차, RGB 대체 19회차, NDVI 1회차다.

- 새 13회차는 원본 10밴드 TIFF에서 직접 만든 RGB 합성과 파장순 10밴드의 무손실 WebP를 사용한다. 기존 1m RGB를 분리해서 만든 밴드가 아니다.
- 표시본은 긴 변 1000px, 최근접, 원본 alpha 유효 영역을 사용한다. 273개 표시 파일이며 원본 해상도라고 표시하지 않는다.
- 컬러바는 원본 전체 alpha 유효 화소의 UInt16 히스토그램에서 Min/P05/P95/Max를 계산한다. 0/65535를 값만으로 제외하거나 1 이상 반사도를 자르지 않는다. 색상 포화만 적용한다.
- 반사도 배율 UInt16/32768과 파장순 444/475/531/560/650/668/705/717/740/842nm는 기존 프로젝트 규약을 이어 쓴다. 새 원본 TIFF에 별도 scale·파장 태그가 없으므로 독립적인 보정 정확도 인증은 아니다.
- 새 회차의 화소·필지 평균 스펙트럼과 NDVI를 이번 작업에서 계산하지 않는다. 등록되지 않은 기능은 비활성 상태를 유지하며 10/7 1회차 자료를 다른 회차에 재사용하지 않는다.
- 분석 TIFF와 원본 Photos·GPS·로컬 경로·비공개 Drive ID를 공개하지 않는다. 큰 TIFF는 비공개 Drive에 보존하고 공유 설정은 변경하지 않는다.
- `published_views.json`과 `catalog.json` 양쪽에 등록하여 다음 자동 갱신에도 유지한다. 표시본과 분석용 원본의 업로드·배포 상태를 구분한다.

2026-10-22 사용자가 제작 완료된 10/7 1회차 다분광 반사도 및 NDVI의 뷰어 배포를 요청했다. 이후 별도 확인에서 영상의 위치·촬영 범위 좌표와 표시용 Drive 파일 ID의 공개에 "이 범위 공개 승인"으로 명시적으로 동의했다. 원본 Photos·개별 GPS 목록·DEM·정량 TIFF·로컬 경로는 공개하지 않는다. Photos를 제외한 자료의 Drive 업로드 허용과 인터넷 전체 공개는 구분한다.

- `published_views.json`: 별도로 제작·검증한 표시용 COG의 승인된 등록 목록. 매일 자동 갱신할 때도 이 목록과 썸네일을 유지한다.
- 동일 id가 자동 조사 결과에도 있으면 이 명시적 등록을 우선한다. 다른 회차는 자동 조사 결과를 유지한다.
- 다분광 RGB는 B6/B4/B2이며 NDVI는 `(B10-B6)/(B10+B6)`이다. 현재 뷰어 표시는 viridis 0~1이며 원 분석값을 변경하지 않는다.
- Drive의 표시 파일은 3밴드 Byte JPEG COG다. 정량 분석의 입력이 아니며, 분석용 10밴드/NDVI TIFF는 별도로 보존한다.
- COG를 읽지 못하면 썸네일 미리보기로 전환하고 화면에 이를 명시한다. 썸네일을 원해상도 영상이라고 표시하지 않는다.
- NDVI에는 고정 컬러바를 표시한다. 비공개 DEM·GPS에 대해서는 '자료 없음'이나 공개 GSD 계산 가능 상태로 오표시하지 않는다.

공유 범위를 바꿀 때는 사용자 승인이 필요하다. 승인되지 않은 날짜나 원자료를 이 등록에 임의로 추가하지 않는다. Drive 상위 자료 폴더 전체를 공개하지 말고, 승인된 표시 파일만 공유한다.

## 2026-10-24 추가 공개 승인

사용자가 이번 배포에서 "검증된 새 자료도 공개 승인"으로 필지 경계·평균 스펙트럼·대표 화소값 및 다른 날짜의 검증된 1m RGB 영상 공개에 동의했다. 10/7 1차의 선택영상 경계와 정제된 회차 CSV도 같은 표시 자료 범위로 포함한다. 원본 Photos·개별 GPS·로컬 경로·분석 TIFF는 계속 제외한다. 19회차의 1m RGB는 실제 광학 카메라 영상이 아니라 기존 다분광의 축소 대체 영상이다.

뷰어는 표시와 저장된 회차 메타데이터 조회만 담당한다. GSD 일괄 계산 UI는 제거했으며 공유 데스크톱 자동화는 유지한다. 검증 범위와 보류 항목은 `drone/updates/20261024_verified_release.html`에 기록한다.

## 2026-10-22 밴드별 보기

사용자 요청에 따라 같은 회차에 파장순 10밴드(444, 475, 531, 560, 650, 668, 705, 717, 740, 842 nm) 보기와 Min–Max / P05–P95 컬러바를 추가했다. 기본은 P05–P95다. RGB 합성과 NDVI는 그대로 유지한다.

20개 표시 이미지(각 1000 × 715 px)와 반사도 범위·파장 정보를 기존 공개 GitHub 뷰어에 추가해도 되는지 별도로 확인했고, 2026-10-22 사용자가 "오케이 배포해보자"로 승인했다.

- `spectral` 메타데이터와 `bands/`의 무손실 WebP 20개는 표시용이다. 원본 10밴드 TIFF를 공개한 것이 아니다. 각 표시 영상은 1000 × 715 px다.
- 범위는 원래 격자의 alpha 유효 화소 92,778,737개 전체에서 밴드별 UInt16 히스토그램으로 정확히 계산했다. P05/P95는 선형 분위수이며 표시 축소본이나 현재 지도 화면에서 계산하지 않는다.
- 컬러맵은 viridis다. P05 아래와 P95 위는 각각 끝 색에 포화시키며, 원본 값이나 유효 영역을 변경하지 않는다. 유효 0/65535를 값만으로 제외하지 않는다.
- 반사도 숫자는 저장 UInt16 / 32768이다. 이 배율은 보정된 Metashape 규약과 프로젝트 기록에 따른 해석이며, 별도 내보내기 로그로 독립 확정한 값은 아니다. 표시 값이 1보다 크다는 이유로 원본을 1로 제한하지 않는다.
- 같은 회차의 표시용 지도 범위와 위치에 대한 기존 공개 승인을 유지한다. 개별 Photos·GPS 목록·DEM·분석 TIFF·로컬 경로는 추가하지 않는다.
## 2026-10-25 화소 스펙트럼 누락 및 RGB 일관성 수정

이 항목은 아래의 과거 배포 시점 기록보다 우선한다. 사용자가 문제 회차 수정과 공개 배포를 요청했다.

- 등록된 다분광 14회차 모두 대표 화소의 10밴드 스펙트럼과 회차별 필지 평균을 연결한다. 누락되었던 13회차에 다른 날짜의 통계를 복사하지 않는다.
- 클릭값은 지도 표시 격자 중심의 최근접 원본 화소다. 원해상도 전체 화소를 내려받는 기능이 아니며 UI에 대표 격자를 표시한다.
- 필지 평균은 공통 19개 경계를 각 원본 좌표계로 변환하고 원해상도 화소 중심을 마스킹한 뒤 alpha 유효 화소만 집계한다. 원본 범위 밖과 무효 영역은 제외하고 포함률을 기록한다.
- RGB 합성과 해당 1m RGB 대체는 같은 등록 다분광 모자이크의 668/560/475nm를 사용한다. 양쪽 모두 같은 원본 전체 유효 화소의 채널별 P05/P95로 표시한다. 1m 대체만 유효 면적 평균으로 축소하므로 질감과 경계는 다를 수 있다.
- 기존 RGB 대체용 Photos 파일명 순 덮어쓰기 모자이크는 해당 14회차의 새 표시본에 사용하지 않는다. 분석 원본과 과거 산출물은 삭제하지 않는다.
- 반사도 단일 밴드의 필지 P05/P95와 RdYlBu_r, NDVI의 viridis 0~1, 10/7의 기존 스펙트럼은 유지한다. 나머지 RGB 전용 5회차에는 존재하지 않는 10밴드 스펙트럼을 만들지 않고 미제공 이유를 표시한다.
- 평균·대표 화소값 공개는 기존의 검증된 새 자료 공개 승인 범위다. Photos, 개별 GPS, 로컬 경로, 분석 TIFF 및 비공개 Drive 자료는 공개하지 않는다.
